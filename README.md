# Wang Soundpad — 手機優先語音音效板

從四支影片整理的 **90 個原聲語句按鈕**。網站採用簡潔深色介面，適合手機觸控，也可於桌面瀏覽器使用。

## 網站

https://kaoelvmpvm.github.io/Wang-soundpad/

## 本次更新（2026-10-26）

- **刪除每句前置間奏**：重新分析四支影片畫面，在人物說話的影片區段建立 90 組新的起訖點。
- **精確切點播放**：使用瀏覽器 Web Audio API 指定音軌區間，直接從語音片段開始播放；遇到下一張文字卡前即停止。
- **手機優先**：簡化操作，手機雙欄語音按鈕、單列可水平滑動的分類、搜尋、收藏，以及底部固定播放／暫停／停止。
- **語句全文顯示**：按鈕文字自動換行，不截斷長句。
- **原音檔保留**：網頁仍讀取 `audio/01.mp3`～`audio/04.mp3`，**不需要重新上傳音檔**。

## 使用

1. 點選語音按鈕，播放單句；再次點選同一按鈕可重播。
2. 搜尋文字，或切換影片一到影片四。
3. 點擊 ★ 收藏喜歡的語句；收藏保留在目前裝置的瀏覽器。
4. 底部播放列可播放／暫停、停止。

## 聲音處理的範圍

「純語音」是指**略去黑底字幕卡及它前後的間奏**，僅播放人物在鏡頭中的說話片段。若原始人物說話片段同時混有音樂或其他人聲，本版不進行可能損壞語音的強制分離。切點依原影片畫面轉場偵測建立，部分語句仍值得人工聽校。

另提供逐句剪輯的 **90 個獨立 MP3** 下載包，適合匯入桌面版聲效軟體。
