# Wang Soundpad — 手機優先語音音效板

從四支影片整理的 **91 個原聲語句按鈕**。網站採用簡潔深色介面，適合手機觸控，也可於桌面瀏覽器使用。

## 使用

1. 點選語音按鈕，播放單句；再次點選同一按鈕可重播。
2. 搜尋文字，或切換影片一到影片四。
3. 點擊 ★ 收藏喜歡的語句；收藏保留在目前裝置的瀏覽器。
4. 底部播放列可播放／暫停、停止。

## 聲音處理的範圍

「純語音」是指**略去黑底字幕卡及它前後的間奏**，僅播放人物在鏡頭中的說話片段。若原始人物說話片段同時混有音樂或其他人聲，本版不進行可能損壞語音的強制分離。切點依原影片畫面轉場偵測建立，部分語句仍值得人工聽校。

另提供逐句剪輯的 **91 個獨立 MP3** 下載包，適合匯入桌面版聲效軟體。

## 發布

使用 GitHub Pages：Settings → Pages → Deploy from a branch → main → /(root)。
四個原音檔位於 `audio/`；網頁沒有第三方字型、追蹤器或 CDN 依賴。

非 Soundpad 官方軟體或品牌產品。
## iPhone 注意事項

使用者觸控後以原生媒體播放通道輸出語音，通常在 iPhone 靜音模式也能播放。背景／App 切換後為避免卡住，系統不自動恢復聲音，點擊底部播放按鈕即可繼續。若 Safari／iOS 發生作業系統層級無聲問題，仍可能需要重新整理或重新開啟 Safari。
