# Wang Soundpad

模仿 Windows 版 Soundpad 深色介面的網頁語音按鈕播放器。

## 使用方式
1. 將提供的音檔壓縮包內四個 `01.mp3`～`04.mp3` 上傳至此儲存庫的 `audio/` 資料夾。
2. 啟用 GitHub Pages：Settings → Pages → Deploy from a branch → main → /(root) → Save。
3. 開啟網站，點選語句按鈕即可播放對應的影片原聲片段。

## 功能
90 句音效、四段來源分類、關鍵字搜尋、收藏、清單／音效按鍵雙視圖、播放／暫停／停止、上一句／下一句、隨機播放、循環、音量調整，以及可在本機儲存的切點微調。

音效是依影片畫面文字卡的約略時間剪取。部分切點可能需微調，並非完整人工逐句聽打。音檔只透過瀏覽器喇叭播放，無法直接注入桌面軟體的虛擬麥克風。
